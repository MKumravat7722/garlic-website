# बाबा सोमनाथ ट्रेडर्स (Baba Somnath Traders) - Premium Indian Garlic Export

A modern, responsive React & Tailwind CSS website crafted to pixel-perfect match the official export showcase design for **बाबा सोमनाथ ट्रेडर्स** (Baba Somnath Traders), based in Indore, Madhya Pradesh, India.

## Features & Sections

- **Header / Navigation:** Official brand logo, quick navigation links (Home, About Us, Products, Quality, Services, Contact Us), mobile navigation menu, and interactive "Get a Quote" action.
- **Hero Section:** "Global Quality Indian Garlic" showcase featuring export freight & agricultural farm imagery, value propositions, and dual CTAs.
- **Value Propositions:** Naturally Grown, Premium Quality, Hygienic Packaging, Global Supply.
- **About Us:** Brand story, Indore Mandi agricultural heritage, and 4 export quality assurances.
- **Our Products:** Interactive cards with technical export specifications:
  - Fresh Garlic Bulbs (40mm - 65mm+)
  - Export Grade Garlic (Uniform 55mm+)
  - Peeled Garlic (HACCP Vacuum Food-Grade Pouches)
  - Custom Packaging (Mesh Bags, Cartons, Palletized Reefer Loading)
- **Quality & Certifications:** 5-point quality checklist and certifications card (FSSAI, APEDA, ISO 9001:2015, Phytosanitary Compliance).
- **Import-Export Solutions:** 6-stage end-to-end process flow (Sourcing → Quality Check → Packing → Logistics → Documentation → Ongoing Support).
- **Global Reach:** Interactive world shipping destinations (UAE, Saudi Arabia, USA, UK, Europe, Bangladesh, Malaysia, Singapore, Indonesia, Africa) with transit time indicators.
- **Direct Connect Banner:** One-tap WhatsApp chat (`+91 9584922249`) and Phone call (`+91 93022232405`).
- **Footer:** Brand overview, quick links, products catalog, complete Indore Mandi address, and social links.
- **Interactive Export Quotation Modal:** Ready-to-use RFQ form supporting FCL container volume inquiries with WhatsApp and email submission.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **Google Fonts** (Playfair Display, Plus Jakarta Sans, Cinzel)

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd garlic-website
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5174](http://localhost:5174) in your browser.

3. Build for production:
   ```bash
   npm run build
   ```
